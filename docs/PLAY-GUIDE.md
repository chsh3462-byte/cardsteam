# NAL-MUK-CARD 플레이 방법

게임 로비의 **처음이라면 · 따라 해보기**를 누르면 로그인 없이 두 번의 내 턴을 연습할 수 있습니다. 실제 전투 엔진으로 드로우, 소환, 주사위 장착, 수호, 다음 턴 공격까지 진행합니다. 연습 눈금은 고정되어 있고 보상을 지급하거나 온라인 상태를 바꾸지 않습니다.

## 첫 대전 준비

1. 아이디와 비밀번호로 가입합니다. `아이디@NALMUK.COM`은 게임 전용 이름이며 실제 이메일 주소가 아닙니다. 가입 시 복구 코드를 보관하세요.
2. 기본 지급 12종으로 구성된 **첫 계약의 수호단**을 선택하면 바로 시작할 수 있습니다. 첫 계약 팩의 랜덤 3장은 추가 카드입니다.
3. 호스팅 시작 → 초대 주소 복사 → 친구에게 전달합니다. 친구는 자기 계정으로 로그인하고 주소를 열어 입장합니다.
4. 핵 체력은 100, 시작 손패는 4장입니다. 상대 핵을 먼저 0으로 만들면 승리합니다.

## 내 턴의 클릭 순서

1. **카드 한 장 뽑기** → 섞인 카드 뒷면 하나 선택 → **필드로 가져가기**. 손패 상한은 8장입니다.
2. **준비:** 손패 계약수 선택 → **계약수 소환**. 비용만큼 에너지를 냅니다. 계약수는 최대 3장, 영구 유물과 예언은 각각 2장입니다. 예언은 이때 설치하세요.
3. **마력석 5개 굴리기.** 굴린 뒤에는 같은 턴에 계약수 소환·예언 설치를 할 수 없습니다.
4. 필드의 내 계약수 선택 → 카드 설명 안에서 **미사용 주사위** 선택 → **주 슬롯에 장착**. 중앙 주사위를 선택하고 필드의 ‘주 ＋’를 눌러도 됩니다.
5. **방금 소환한 일반 계약수는 이번 턴 공격 불가.** 주 슬롯을 채우고 **수호 자세로 바꾸기**로 방어하세요. 각성한 속공 계약수는 예외입니다.
6. 기존 계약수가 공격할 수 있다면 **공격 자세**인지 확인 → **공격하기** → 붉은 상대 계약수 선택. 상대 필드가 비어 있으면 상대 **CORE 숫자**를 선택합니다. 자세 변경 버튼은 공격 실행 버튼이 아닙니다.
7. 마도술은 손패 선택 → 미사용 주사위 선택 → **카드 발동** → 효과 대상 선택. 대상 없는 회복 등은 바로 발동합니다.
8. 끝났다면 **턴 종료**. 상대 턴 동안 내 장착 눈금은 유지됩니다. 다음 내 턴에는 에너지가 충전되고 내 주사위는 초기화되므로 다시 굴려 장착해야 합니다.

각 계약수는 턴당 한 번 공격합니다. 공격 후에는 주사위와 자세를 바꿀 수 없습니다. 공격 전에는 채워진 슬롯을 눌러 주사위를 해제하고 옮길 수 있습니다. 에너지는 처음 4, 두 턴마다 최대치가 1 늘어 최대 8입니다. 남은 에너지를 더해 누적하는 방식은 아닙니다.

## 위력과 주사위

- 기본 위력 4 × 주 눈금 5 = 전투력 20.
- 보조 눈금은 공격 배수에 합산하지 않습니다. ‘같은 눈금 2개’ 각성 조건에 사용합니다.
- 각성 조건은 카드마다 짝수, 홀수, 5 이상, 6, 같은 눈금 2개 중 하나입니다. 페어 이외에는 주 슬롯만 확인합니다.
- 각성 시 기본 위력 +2(최대 10)와 고유 효과를 얻습니다. 조건을 잃으면 각성이 풀립니다.
- 리롤: 미사용 주사위 아래 체크박스 선택 → 리롤. 기본 턴당 1회, 에너지 1 필요. 장착·소비된 주사위는 제외됩니다.
- 눈금 복사 도구: 원본 주사위 선택 → 카드 발동 → 중앙에서 **다른** 미사용 주사위 선택.
- 카드 비용인 에너지와, 효과에 사용하는 주사위는 별개의 자원입니다.

## 교전과 예언

수호 자세인 상대는 장착 전투력만큼 들어오는 일반 공격 피해를 줄입니다. 예를 들어 내 전투력 20, 상대 수호 전투력 12면 안정도 피해는 8입니다. 주사위를 장착한 수호 계약수는 다른 계약수보다 먼저 공격해야 합니다.

공격 자세인 상대에게는 전투력만큼 피해를 주고, 상대 전투력 절반(버림)의 반격을 받습니다. 수호의 일반 반격은 없지만 가시 등 고유 효과가 추가될 수 있습니다. 안정도가 0인 계약수는 소멸합니다. 핵의 보호 수치는 핵 피해를 먼저 흡수합니다.

예언은 자신 또는 상대의 **실제 굴림·리롤**이 카드 조건을 만족할 때 자동으로 발동하고 소멸합니다. 공격 선언만으로 발동하지 않습니다. 주사위 조작 도구는 새로운 굴림이 아닙니다.

## 버튼이 비활성화되었을 때

| 상황 | 확인할 것 |
| --- | --- |
| 소환 안 됨 | 드로우 완료, 준비 단계, 에너지, 빈 마법진 |
| 공격 안 됨 | 주 슬롯, 공격 자세, 소환 대기/빙결, 이미 공격했는지 |
| 마도술 발동 안 됨 | 굴림 완료, 미사용 주사위 선택, 에너지, 필요한 대상 존재 |
| 발동 후 변화 없음 | 대상 선택 중인지 확인하고 붉은 대상 또는 지정된 아군을 클릭 |
| 주사위 선택 안 됨 | 장착/소비 상태 확인. 복구 도구만 소비된 주사위 선택 |
| 전부 안 됨 | 상대 차례, 굴림 애니메이션, 서버 처리, 재연결 상태 확인 |

카드 설명에는 현재 사용할 수 없는 이유가 표시됩니다. 전장 위 **다음 행동** 안내와 **플레이 방법**도 언제든 볼 수 있습니다.

## 저장과 경기 보상

수집 카드·팩·포인트·경험치는 서버에 자동 저장됩니다. 이름·덱은 계정 저장 버튼으로도 저장할 수 있습니다. 한 판을 마치면 각 참가자에게 1포인트와 일반 5장 팩을 지급합니다. 일반/레어/에픽 팩은 각각 10/50/100포인트입니다. 중복 카드는 R 10, SR 40, SSR 200 경험치가 됩니다. 대기 방, 만료된 미완료 경기, 연습은 보상을 지급하지 않습니다.
