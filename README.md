# HEX HAVOC — 룬 계약 결투

**300장의 오리지널 일러스트, 개별 주사위 배수, 방 코드 온라인 2인 카드 대전.**

실행: https://hex-havoc-dice-dungeon.chsh3462.chatgpt.site

GitHub: https://github.com/chsh3462-byte/cardsteam

## 수집 · 등급 · 카드팩

- 300장: 계약수 150 / 마도술 50 / 연금 도구 60 / 비전 룬 40.
- R 180장 / SR 87장 / SSR 33장. 카드 종류별 위력, 체력, 효과량, 발동 조건과 에너지 효율을 점수화하고 종류 내 상위 점수에 상위 등급을 부여합니다. 동일 점수에는 동일 등급이 적용됩니다. 등급은 추가 능력치를 부여하지 않습니다.
- 첫 접속: 기본 R 카드 12종을 지급합니다. 수집한 카드는 덱에 최대 2장씩 쓸 수 있으므로 기본 24장 덱으로 바로 대전할 수 있습니다. 별도로 랜덤 3장의 첫 계약 팩을 1회 지급합니다.
- 완료된 경기: 승리·패배·무승부·항복에 관계없이 각 참가자에게 **1포인트 + 일반 5장 팩 1개**. 상대가 입장하지 않은 방과 만료된 미완료 경기는 보상이 없습니다.
- 한 번 수집한 카드는 영구 보유합니다. 중복은 R 10 / SR 40 / SSR 200 XP로 즉시 전환하며, 같은 팩 안의 중복도 적용합니다.
- 레벨 L에서 다음 레벨에 필요한 XP는 `L × 100`. 경험치는 누적되며 레벨은 수집 기록용입니다. 대전 능력치를 올리지 않습니다.

|---|---:|---:|---:|---:|---:|
| 첫 계약 | 첫 접속 지급 | 3 | 96.9% | 3% | 0.1% |

각 장은 독립 추첨입니다. 먼저 등급을 뽑고 그 등급의 카드 중 균등 선택합니다. 천장/확정 카드는 없습니다. 구매와 개봉은 서버에서 처리하고, 새로고침·동시 클릭·요청 재시도는 추가 결제나 보상을 만들지 않습니다.

## 대전

24장 덱, 계약수 10장 이상, 같은 카드 최대 2장. 보유한 카드만 사용합니다. 핵 체력 100, 시작 손패 4장. 매 턴 뒷면을 골라 한 장을 뽑고 소환·설치한 뒤 마력석 5개를 슬롯처럼 순서대로 굴립니다.

계약수 3칸, 유물 2칸, 예언 2칸. 계약수의 **기본 위력(1–10) × 장착 눈금(1–6)**으로 전투합니다. 보조 슬롯의 눈금과 짝수·홀수·5 이상·6·같은 눈금 2개 조건으로 오버클럭합니다. 각성은 기본 위력 +2(최대10)와 고유 효과를 켭니다. 예언은 자신/상대의 실제 굴림 조건에 반응합니다. 수호는 상대 턴에도 유지됩니다.

게임의 **호스팅 시작**을 누르면 친구에게 보낼 접속 주소가 만들어집니다. **주소 복사/공유**로 보내고, 친구는 링크를 열어 이름·덱을 고른 뒤 입장합니다. 접속 주소 또는 8자리 코드를 직접 붙여넣어도 됩니다. 대기 중 **호스팅 종료**를 누르면 그 주소가 닫힙니다. 방은 생성 후 24시간 유효하며, 현재 운영 중인 게임 링크에서는 별도 Cloudflare 계정 설정이 필요 없습니다. 서버가 손패를 숨기고 모든 행동을 검증합니다. Sites 링크에서는 두 참가자 모두 사이트 접근 권한이 필요합니다.

## 실행과 배포

Node.js 22 이상:

```sh
npm run build
npm test
```

빌드 결과는 `dist/server/index.js`입니다. 게임 실행과 빌드에는 외부 npm 의존성이 없습니다. 모든 그림은 저장소의 12개 WebP 아틀라스에서 제공하며, 300개 카드가 각각 다른 셀을 사용합니다. 원본 코드와 이미지가 함께 제공됩니다.

**GitHub 배포:** [설정 안내](docs/GITHUB-DEPLOY.md). GitHub Actions가 Cloudflare Worker + R2 전체를 배포합니다. GitHub Pages만으로 서버 대전을 실행하지 않습니다. 최초 배포에는 Cloudflare 계정·Access 로그인·R2 및 GitHub 환경 설정이 필요합니다.

`.openai/hosting.json`은 기존 Sites 배포에서만 사용하는 메타데이터입니다. GitHub 배포에는 필요하지 않습니다. 신원·포인트·수집함 데이터는 GitHub에 포함하지 않습니다.
