# NAL-MUK-CARD

**300장의 오리지널 일러스트, 개별 주사위 배수, 방 코드 온라인 2인 카드 대전.**

실행: https://hex-havoc-dice-dungeon.chsh3462.chatgpt.site

GitHub: https://github.com/chsh3462-byte/cardsteam

## 수집 · 등급 · 카드팩

- 300장: 계약수 150 / 마도술 50 / 연금 도구 60 / 비전 룬 40.
- R 180장 / SR 87장 / SSR 33장. 카드 종류별 위력, 체력, 효과량, 발동 조건과 에너지 효율을 점수화하고 종류 내 상위 점수에 상위 등급을 부여합니다. 동일 점수에는 동일 등급이 적용됩니다. 등급은 추가 능력치를 부여하지 않습니다.
- 첫 접속: 기본 R 카드 12종을 지급합니다. 수집한 카드는 덱에 최대 2장씩 쓸 수 있으므로 기본 24장 덱으로 바로 대전할 수 있습니다. 별도로 랜덤 3장의 첫 계약 팩을 1회 지급합니다.
- 완료된 경기: 승리·패배·무승부·항복에 관계없이 각 참가자에게 **1포인트 + 일반 5장 팩 1개**. 상대가 입장하지 않은 방과 만료된 미완료 경기는 보상이 없습니다.
- 한 번 수집한 카드는 영구 보유합니다. 중복은 R 10 / SR 40 / SSR 200 XP로 즉시 전환하며, 같은 팩 안의 중복도 적용합니다.
- 레벨 L에서 다음 레벨에 필요한 XP는 `L × 100`. 경험치는 누적되며 레벨은 수집 기록용입니다. 대전 능력치를 올리지 않습니다.

| 팩 | 가격 | 카드 수 | R | SR | SSR |
|---|---:|---:|---:|---:|---:|
| 첫 계약 | 첫 접속 지급 | 3 | 96.9% | 3% | 0.1% |
| 일반 | 10 포인트 / 경기 보상 | 5 | 96.9% | 3% | 0.1% |
| 레어 | 50 포인트 | 5 | 89.5% | 10% | 0.5% |
| 에픽 | 100 포인트 | 5 | 73% | 25% | 2% |

각 장은 독립 추첨입니다. 먼저 등급을 뽑고 그 등급의 카드 중 균등 선택합니다. 천장/확정 카드는 없습니다. 구매와 개봉은 서버에서 처리하고, 새로고침·동시 클릭·요청 재시도는 추가 결제나 보상을 만들지 않습니다.

## 대전

처음이라면 로비의 **처음이라면 · 따라 해보기**로 두 번의 내 턴을 연습하세요. 로그인 없이 실제 규칙으로 소환·주사위 장착·수호·다음 턴 공격을 익힐 수 있습니다. 게임 안 **플레이 방법**과 [자세한 플레이 안내](docs/PLAY-GUIDE.md)에서 클릭 순서, 카드별 사용 시점, 공격 불가 이유를 확인할 수 있습니다. 전장 위 안내는 현재 가능한 다음 행동을 보여 줍니다.

24장 덱, 계약수 10장 이상, 같은 카드 최대 2장. 보유한 카드만 사용합니다. 핵 체력 100, 시작 손패 4장. 매 턴 뒷면을 골라 한 장을 뽑고 소환·설치한 뒤 마력석 5개를 슬롯처럼 순서대로 굴립니다.

계약수 3칸, 유물 2칸, 예언 2칸. 계약수의 **기본 위력(1–10) × 장착 눈금(1–6)**으로 전투합니다. 보조 슬롯의 눈금과 짝수·홀수·5 이상·6·같은 눈금 2개 조건으로 오버클럭합니다. 각성은 기본 위력 +2(최대10)와 고유 효과를 켭니다. 예언은 자신/상대의 실제 굴림 조건에 반응합니다. 수호는 상대 턴에도 유지됩니다.

게임의 **호스팅 시작**을 누르면 친구에게 보낼 접속 주소가 만들어집니다. **주소 복사/공유**로 보내고, 친구는 링크를 열어 이름·덱을 고른 뒤 입장합니다. 접속 주소 또는 8자리 코드를 직접 붙여넣어도 됩니다. 대기 중 **호스팅 종료**를 누르면 그 주소가 닫힙니다. 방은 생성 후 24시간 유효하며, 현재 운영 중인 게임 링크에서는 별도 Cloudflare 계정 설정이 필요 없습니다. 서버가 손패를 숨기고 모든 행동을 검증합니다. 현재 Sites 게임은 링크로 누구나 열 수 있습니다. 대전·수집·포인트 사용은 각자 `아이디@NALMUK.COM` 게임 계정으로 로그인해야 하며, 친구별 초대 등록은 필요 없습니다. 로그인 전에는 카드 도감을 둘러볼 수 있습니다.

## 실행과 배포

Node.js 22 이상:

```sh
npm run build
npm test
```

빌드 결과는 `dist/server/index.js`입니다. 게임 실행과 빌드에는 외부 npm 의존성이 없습니다. 모든 그림은 저장소의 12개 WebP 아틀라스에서 제공하며, 300개 카드가 각각 다른 셀을 사용합니다. 원본 코드와 이미지가 함께 제공됩니다.

**GitHub 배포:** [설정 안내](docs/GITHUB-DEPLOY.md). GitHub Actions가 Cloudflare Worker + R2 전체를 배포합니다. GitHub Pages만으로 서버 대전을 실행하지 않습니다. 최초 배포에는 Cloudflare 계정·R2 및 GitHub 환경 설정이 필요합니다.

`.openai/hosting.json`은 기존 Sites 배포에서만 사용하는 메타데이터입니다. GitHub 배포에는 필요하지 않습니다. 신원·포인트·수집함 데이터는 GitHub에 포함하지 않습니다.


## 게임 계정과 저장

- 회원가입: 영문으로 시작하는 영문·숫자·밑줄 3~20자의 아이디와 10~128자 비밀번호. `아이디@NALMUK.COM`은 게임 전용 가상 이메일이며 실제 메일 수신/발송, 도메인 소유권과 무관합니다.
- 비밀번호는 계정별 무작위 salt와 PBKDF2-SHA256 100,000회 해시로 보관합니다. 원문 비밀번호는 저장하지 않습니다. 로그인은 30일 유효한 무작위 세션과 Secure/HttpOnly/SameSite 쿠키를 사용합니다.
- 가입 시 256비트 복구 코드를 한 번 표시하며 파일 다운로드를 제공합니다. 코드로 비밀번호를 재설정하면 코드가 교체되고 기존 로그인 세션은 모두 무효화됩니다. 실제 이메일을 통한 재설정은 없습니다.
- R2에 카드, 팩, 포인트, 경험치, 경기 보상과 덱/이름을 저장합니다. 대전·보상·개봉 즉시 자동 저장, 덱 선택·이름 변경·대전 시작 시 저장합니다. 계정 메뉴에서 수동 저장도 가능합니다.
- 기존 Sites 계정 기록은 가입 화면의 연결 옵션으로 한 게임 계정에만 이전할 수 있습니다. 해당 브라우저에서 기존 ChatGPT 로그인이 확인되고 기존 저장본이 있을 때만 연결됩니다. 중복 이전은 서버에서 차단합니다.
- `AUTH_MODE=game`인 독립 배포는 게임 계정만 사용하며 외부 플랫폼 신원 헤더를 무시합니다. Sites에서는 신원 헤더를 기존 기록 이전에만 사용하며 게임 로그인에는 사용하지 않습니다.
- `accounts-v1/`, `sessions-v1/`, `auth-limits-v1/`, `legacy-claims-v1/`는 서버 전용 데이터입니다. 비밀번호 추측 요청을 계정 및 IP별로 제한합니다. 기존 `collection-v1/`, `duel-v4/` 저장본은 보존합니다.
